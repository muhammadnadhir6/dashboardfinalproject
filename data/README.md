- `id_debitur`
- `sektor_usaha`
- `omzet_bulanan`
- `lama_usaha_tahun`
- `jumlah_karyawan`
- `plafon_kredit`
- `skor_kredit_internal`
- `rasio_cicilan_omzet`
- `jumlah_tunggakan_historis`
- `jenis_produk_kredit`
- `biaya_operasional_bulanan`
- `pertumbuhan_omzet_yoy`
- `kepemilikan_agunan`
- `status_kepemilikan_tempat_usaha`
- `channel_pengajuan_kredit`
- `flag_gagal_bayar`

Kolom `nama_nasabah` **opsional**. Jika tersedia, fitur pencarian nama otomatis aktif. Dataset notebook asli tidak memiliki kolom nama nasabah.
